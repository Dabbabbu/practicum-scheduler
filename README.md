# 임상실습 스케줄러 · 성적 자동 기입

영상의학과지원부 **학생 임상실습** 업무용 도구 두 가지입니다.

1. **스케줄 자동 생성기** (`index.html`) — 학교별 실습생을 방(검사실)에 날짜별로 배정하고 일정표를 만듭니다.
2. **평가표 자동 기입** (`tools/fill_eval.py`) — 성적산출표(.xlsx)를 읽어 학교에서 보내온 빈 평가표 PDF에 동그라미·점수·등급을 채웁니다.

> 학생 이름·학번 등 개인정보는 들어 있지 않습니다. 명단은 프로그램을 열어 직접 입력하고, 브라우저 안에서만 쓰입니다 (서버로 보내지 않음).

## 1. 스케줄 자동 생성기

브라우저에서 [열기](https://dabbabbu.github.io/practicum-scheduler/) 하거나 `index.html`을 더블클릭하면 바로 쓸 수 있습니다. 설치할 것이 없는 단일 HTML 파일입니다.

- **학교별 실습생**: 학교 3곳(숫자 · 알파벳 · 한글 번호)까지, 인원과 이름을 넣습니다. 이름을 비워 두면 번호로만 배정합니다.
- **하계 · 동계 프리셋**: 기간과 학교 구성을 한 번에 바꿉니다.
- **방 배정 규칙**: 검사실마다 하루 인원, 실습생이 꼭 거쳐야 하는 방, 특정 학생만 갈 수 있는 방을 정할 수 있습니다.
- **자동 생성 후 손보기**: 칸을 눌러 학생을 바꾸고, 겹치거나 빠진 배정은 색으로 표시됩니다.
- **출력**: 일정표를 인쇄(PDF 저장)하거나 표를 복사해 엑셀에 붙일 수 있습니다.

## 2. 평가표 자동 기입 (`tools/fill_eval.py`)

성적산출표의 점수를 학교 양식 PDF(스캔본, 학생 1명 = 1페이지)에 기입합니다.

```bash
pip install openpyxl pypdf reportlab pypdfium2 pillow numpy

python tools/fill_eval.py \
  --xlsx "26년 하계 ... 성적산출표.xlsx" \
  --pdf  "학생성적_영상_평가전.pdf" \
  --out  "학생성적_영상_평가완료.pdf" \
  --school 대구보건대학교
```

- 산출표에 `번호 · 학교 · 이름 · 출결(40) · 성적` 열이 있어야 합니다.
- 총점 = `성적`, 출석 = `출결(40)`, 나머지 점수는 12개 평가 항목에 고르게 나눠 감점합니다.
- 등급: A+ (95~) · A (90~94) · B+ (85~89) · B (80~84) · C+ (~79). 학교별 1등은 **실습수석**.
- 평가자 서명·도장 칸은 비워 둡니다 (직접 날인).
- 양식이 바뀌면 스크립트 위쪽 `DEFAULT_LAYOUT` 좌표를 고치거나 `--layout layout.json`으로 덮어씁니다.
- PDF 페이지 순서가 산출표 번호 순서와 같은지 **눈으로 확인**하세요 (인원 수만 검사합니다).

자세한 사용법은 [`tools/사용법.txt`](tools/사용법.txt)에 있습니다.

## 주의

- 학생 명단·성적·평가표는 개인정보입니다. 이 저장소에는 올리지 말고, 만든 PDF도 병원 규정에 따라 보관하세요.
- 업무 편의를 위한 도구이며, 최종 점수와 평가는 작성자가 확인해야 합니다.
