실습학생 평가표 자동 기입 (fill_eval.py) 사용법
================================================

1) 최초 1회 준비 (Windows PowerShell / CMD)
   pip install openpyxl pypdf reportlab pypdfium2 pillow numpy

2) 실행 (파일이 있는 폴더에서)
   python fill_eval.py --xlsx "26년 하계 ... 성적산출표.xlsx" ^
                       --pdf  "26년하계대구보건대학교학생성적_영상_평가전.pdf" ^
                       --out  "26년하계대구보건대학교학생성적_영상_평가완료.pdf" ^
                       --school 대구보건대학교

   옵션
     --school     산출표 '학교' 열 값 (기본: 대구보건대학교). 대구가톨릭대 분을 만들 땐 --school 대구가톨릭대학교
     --sheet      산출표 시트 이름 (생략 시 첫 시트)
     --no-suseok  1등에게 '실습수석' 대신 등급을 적음
     --layout     양식이 바뀐 경우 좌표 JSON 파일로 덮어쓰기 (스크립트 상단 DEFAULT_LAYOUT 참고)
     --font       한글 폰트 파일 경로 (기본: C:/Windows/Fonts/malgunbd.ttf 자동 탐색)

3) 산출표 조건
   - 헤더 행에 '번호','학교','이름','출결(40)','성적' 열이 있어야 함 (현재 v7 양식 그대로 OK)
   - PDF 페이지 순서 = 해당 학교 학생의 산출표 번호 순서여야 함 (스크립트가 인원 수는 검사하지만
     순서는 검사하지 못하므로 학번·이름을 눈으로 확인할 것)

4) 적용 규칙
   총점=성적 열 / 출석=출결 열 / 12항목 골고루 감점 / 등급 A+(95~) A(90~) B+(85~) B(80~) C+(~79)
   해당 학교 1등 = '실습수석' / 서명·도장 칸은 비움(직접 날인)
